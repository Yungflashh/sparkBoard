# Robokido IDE

Visual programming for the Robokido humanoid. Vite + React.

```
npm i
npm run dev
```

Then http://localhost:5173.

Drag blocks from the left palette into a Division (one per robot). A Division has Subdivisions (reusable groups) that chain into a sequence. Hit Preview to run the program on a stick figure; flip on Mission mode and the robot has to walk to an apple and carry it home.

SEND copies the JSON payload to clipboard. Point Settings → endpoint at your robot to POST instead.
